Inventario
Project

API REST para gestión de inventario de productos y categorías. Autenticación JWT, paginación, filtros y documentación interactiva.

Estado ● Online
Framework Django REST Framework
Autenticación JWT (SimpleJWT)
Base de datos PostgreSQL
Autor Juan Pablo Buitrago Naranjo

Accesos rápidos

01
API Root
Explorador interactivo de todos los endpoints disponibles.
02
Documentación
Swagger UI con descripción completa de la API y pruebas en vivo.
03
Frontend
Interfaz web para gestionar el inventario de forma visual.

Endpoints principales

POST /api/token/ Obtener token JWT
GET /api/productos/ Listar todos los productos (paginado)
POST /api/productos/ Crear nuevo producto
PUT /api/productos/{id}/ Actualizar producto existente
DELETE /api/productos/{id}/ Eliminar producto
GET /api/categorias/ Listar todas las categorías
GET /api/estadisticas/ Resumen general del inventario
GET /api/docs/ Documentación Swagger interactiva
